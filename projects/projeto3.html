Motion Type

Tipografia em movimento

A Dança das Letras

Motion Type é uma exploração experimental da tipografia em movimento. Cada letra é tratada como um ator com personalidade própria, capaz de expressar emoção através de movimento.

O projeto utiliza princípios de animação tradicional combinados com técnicas modernas de motion graphics para criar uma linguagem visual única onde o texto transcende sua função comunicativa básica.
