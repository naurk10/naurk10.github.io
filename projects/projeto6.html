Typography Lab

Experimentos tipográficos sem limites

O Laboratório de Letras

Typography Lab é uma série de experimentos tipográficos que desafiam as convenções tradicionais do design de tipos. Cada experimento explora um conceito diferente: distorção, modularidade, interatividade, e expressão emocional através da forma.

O projeto nasceu de uma pergunta simples: "O que acontece quando deixamos de lado as regras?" A resposta foi uma jornada fascinante através de territórios tipográficos inexplorados.

Sistema Modular

Um dos experimentos mais interessantes foi a criação de um sistema tipográfico modular onde cada letra é construída a partir de componentes básicos que podem ser rearranjados infinitamente.

Este sistema permite criar variações ilimitadas enquanto mantém uma coerência visual fundamental.
