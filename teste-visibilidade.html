Passos de Troubleshooting:

  1. Force Refresh: Pressione Ctrl + F5 (Windows) ou Cmd + Shift + R (Mac)
  2. Cache do Navegador: Limpe o cache ou abra em modo anônimo (Ctrl+Shift+N)
  3. Verificar Console: Pressione F12 → Console. Veja se há erros em vermelho
  4. Verificar CSS: F12 → Elements → Verifique se os elementos têm opacity: 0
  5. Desativar Extensões: Algumas extensões de navegador podem bloquear CSS/JS
